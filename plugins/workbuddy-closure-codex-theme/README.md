# 可露希尔 · Codex 深色主题（WorkBuddy 桌面版）

复刻本项目当前 Codex 深色主题，并沿用已确认的 DSH 整列侧栏效果。版本 `0.1.1`，针对 Windows x64、WorkBuddy `5.11.3`。

- 深蓝黑 `#0a0b16`、冷白 `#eef0ff`、洋红 `#ff3ea5`。
- 顶栏、窗口按钮底部和整个左侧任务/工作区共享紫蓝渐变与 8 px 网格。
- 转角连续；洋红分隔线随侧栏展开、折叠及宽度调整移动。
- 聊天区环境光、3 px CRT 扫描线和暗角；保留原生布局与操作。
- Cascadia Mono 字体，中文回退等线、微软雅黑；不附带字体、不改变字号。
- 映射 316 个桌面与聊天组件变量，包含输入框、弹出菜单、状态、差异及独立设置窗口。
- 独立设置窗口顶部使用纯深色背景，不绘制网格装饰条。

## 启用

1. 将完整主题包解压到准备长期保留的位置。
2. 首次启用前，保存当前工作，**从托盘退出 WorkBuddy**。
3. 双击 **`Enable-Theme.vbs`**，会使用原有账号与配置启动 WorkBuddy 并加载主题。

以后也使用该入口启动。源码仓库中的对应入口是根目录 **`Enable-WorkBuddy-Theme.vbs`**。完整发行包自带 Node.js，无需自行安装；直接使用源码目录时需要 Node.js 22 及以上版本，或本仓库已有的 Electron 运行时。

如果普通 WorkBuddy 仍开着，入口会尝试正常关闭窗口；遇到后台驻留时会提示先从托盘退出，不强制结束任务。成功时不弹提示；错误日志位于 `%LOCALAPPDATA%\ClosureWorkBuddyTheme\launcher.log`。

## 恢复

双击 **`Restore-Theme.vbs`**，当前窗口会恢复原外观，输入框草稿会保留。仓库根目录对应 **`Restore-WorkBuddy-Appearance.vbs`**。随后正常退出并从原版入口重新打开 WorkBuddy，可一并关闭此次主题启动使用的本机连接端口。

程序只保存自身启动状态，账号、会话、模型、隐私偏好和持久化外观设置仍由 WorkBuddy 管理。未修改安装目录，关闭主题不需要还原或重装安装包。

## 桌面支持方式

WorkBuddy 5.11.3 随包的 `.codebuddy-plugin` 外观 Mod 模板面向 CBC Web；桌面渲染器使用另一套外观系统。本包是**独立桌面主题扩展**，通过 WorkBuddy 自带的本机调试启动开关加载样式，不冒充内置 Mod 中心可安装的插件，也不是其在线外观商店主题。

主题连接限本机回环地址，并校验端口所属进程及安装路径；仅处理已安装 WorkBuddy 的 `renderer/index.html`，包括由该入口承载的设置窗口，不处理第三方网页或嵌入文档。助手不调用聊天、文件或网络业务接口。退出 WorkBuddy 后助手自动结束。

本版经过安装包真实渲染器的后台测试，使用隔离的合成账号、任务与工作区数据，并阻断远程请求。验证三个尺寸、菜单、侧栏折叠、独立设置页、草稿保留和完整撤销；不等同于已登录桌面会话的端到端测试。WorkBuddy 升级后如界面结构变化，可能需要重新适配。

## 构建

```powershell
node tools/build.mjs
```

源码在 `src/`，已构建样式与控制器在 `lib/`。源码无需 npm 依赖。工程根目录的构建与后台测试说明见 `docs/WORKBUDDY-THEME.md`。
