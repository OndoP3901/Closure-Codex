可露希尔 CRT 叠层 · Windows

这是可选组件。安装器和 Windows 登录启动项都不会启动它，桌宠也不需要它。
只有手动双击 ClosureCrt.exe 时，叠层才会出现在 Codex 窗口上。不需要改变 Codex 界面时请不要运行。
托盘里的 Closure CRT 菜单可以开关扫描线和暗角，或选择退出。

暗角默认跟随 Windows 应用颜色。右键点击桌宠并展开「CRT 显示效果」，可分别开关扫描线和暗角、调整强度并选择跟随系统、深色或浅色。设置在重启后保留。单独运行 CRT 时也可从托盘切换模式。

工具只在 Microsoft Store 版 Codex/ChatGPT 的主尺寸窗口位于前台时显示。扫描线按窗口 DPI 缩放，鼠标点击穿透。切到其他程序或最小化后会隐藏。此叠层位于 Codex 窗口上方，原 DSH 的扫描线位于其页面渲染层内，因此菜单和弹层上的表现可能有差异。
