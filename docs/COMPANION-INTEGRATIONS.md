# Codex、DSH 与 WorkBuddy 桌宠联动

在桌宠的右键菜单中分别勾选「Codex 联动」「DSH 联动」「WorkBuddy 联动」，三项可以同时启用。全新配置默认关闭联动。开机自启、桌面显示范围和语音设置各自保存。

三款软件共用原有 Codex 联动的场景和默认语音队列，包括任务开始、持续工作、完成、工具失败、提问和回答。切换为个人队列后，三款软件也共用该个人队列，不会重置已有台词。仅在首次开启任意联动、或联动模式重新加载时播放启动场景。

所有已启用且连接的软件中，提示、工作动画和场景语音统一跟随最近有真实活动的对话，同一软件内的多个对话也分别比较。使用宿主事件时间排序；开始、输出、工具执行、提问、回答和任务结束都算活动，连接心跳、余额刷新不改变优先来源。最新对话刚完成时，保留其完成状态；其他对话出现新活动后再切换。

切换对话时收起上一段对话的提示，重置工作和闲置计时；已经略过的提示不补播，重新连接也不补播历史事件。默认与个人语音队列继续共用，轮换进度保留。用户可在右键菜单关闭不需要的软件联动。

余额不再自动弹出。用鼠标中键点击桌宠时，气泡分别显示所有已启用且连接工具的账号余额或额度；未连接工具不显示，全部未连接时不弹出余额气泡。余额查询失败或未登录时，对已连接工具显示对应状态。左键保留原来的台词互动，右键打开设置。原先保存的每分钟或每五分钟提醒设置自动迁移为手动查看。

关闭「在桌面和其他软件中显示」后，只在已勾选联动软件的主窗口前台显示；未勾选任何联动时保留原有 Codex 前台显示行为。桌面模式不受软件最小化影响。

## DSH

安装 `dsh-closure-companion-bridge` 插件到 DSH 桌面配置，然后勾选桌宠菜单的「DSH 联动」。插件与 DSH 主题相互独立，不会在软件里创建第二只桌宠。

发行包的 `plugins/dsh-companion` 包含 `.tgz` 安装包，可通过 DSH 插件管理界面安装，或执行 `dsh plugin --profile desktop add <包路径>`。安装后若菜单仍提示等待宿主插件连接，重新打开 DSH 即可。

官方余额直接调用 DSH 内置 `deepseekAccount.getBalance`，分开显示充值余额和赠送余额，保留币种。已登录但查询失败时显示暂不可用，未登录时显示未登录，不把失败当作零余额。

## WorkBuddy

WorkBuddy 桌面版通过启动时开放的本机连接读取原生 SDK 事件和 `auth:getAccountUsage`。菜单勾选后，使用以下任一入口启动：

- 现有「WorkBuddy · 可露希尔主题」快捷方式，可同时使用主题与桌宠联动。
- 根目录 `Start-WorkBuddy-Companion.vbs`，只建立联动连接，保留 WorkBuddy 当前外观。

若普通 WorkBuddy 已在运行但没有开放连接，先从托盘退出，再使用入口重新启动。联动启动入口不会强制终止已有任务。无需另装 Node.js，它使用发行包附带的 Electron 运行时。

积分直接取 WorkBuddy 软件当前官方账号的 `usageLeft`，支持企业账号不限量状态。更换账号会清空旧数值并重新查询。积分是账号当前剩余积分，不根据模型价格估算。退出 WorkBuddy 后显示等待连接，重新从支持联动的入口启动后自动恢复。

## 范围与后台验证

适配 DSH 0.2.2-rc.5、WorkBuddy 5.11.3 和现有 Codex 联动。两个新增软件的第三方模型、中转站余额查询暂未实现；原 Codex 的余额能力保持可用。

官方余额数据每分钟刷新，任务结束后补刷；刷新不会主动弹出气泡。关闭对应联动后停止连接和查询。DSH 以本机心跳租约控制查询，桌宠异常退出后租约自动失效。WorkBuddy 连接限定回环地址、已安装程序的端口及主页面，不读取其他网页。Codex 结合活动订阅及本机程序运行状态判断连接状态。

新增连接只输出事件计数、任务状态、余额与可用的 Token 统计，不持久化登录凭据、提问正文、回答正文或工具参数。应用升级后接口或页面模块可能变化；无法接入时显示等待连接，不猜测余额。

开发验证：`node --test tests/integrations.test.cjs tests/runtime-settings.test.cjs tests/token-usage.test.cjs tests/window-follow.test.cjs`；DSH 真实隔离宿主验证：`node tools/test-dsh-companion.cjs`。桌宠使用 `--smoke --mute-audio` 在独立配置和隐藏窗口中验证。
